# 默认经济设定

小数表格价格先四舍五入为整数。基础收购价 = 表格价格 × 出售倍率（默认 1）；当日市场收购价 = 基础收购价 ×（1 + 涨跌幅）。完成倍率和涨跌计算后，对单件价格四舍五入，再乘出售数量。新版表格以 2.1 的实际收购价作为 1 倍基准，因此默认基础收益保持一致。

默认 50 次每日上限与原抽取权重下，无附魔时每日全部渔获的基础收购期望约 **490 绿宝石**。这些是扣除维修、购竿和附魔费用前的期望值，实际收益随抽取与行情变化；囤货、双倍产出和自定义奖池会影响结果。

## 固定开销

| 鱼竿 | 购买价 | 初始耐久 | 回收价 |
| :--- | ---: | ---: | ---: |
| 木钓鱼竿 | 100 | 30 | 0 |
| 铁钓鱼竿 | 300 | 50 | 0 |
| 金钓鱼竿 | 700 | 70 | 0 |
| 钻石钓鱼竿 | 1500 | 100 | 0 |
| 下界合金钓鱼竿 | 3100 | 150 | 0 |

维修一次默认 150 绿宝石，补满耐久；附魔一次默认消耗 300 绿宝石和一本附魔书，成功率默认 50%。费用与成功率均可配置，100% 为必定成功，帮助菜单随配置同步更新。新用户的免费木竿和 100 绿宝石仅发放一次。

各级附魔按配置的总加成生效：默认耐久为 30/70/120，海之眷顾为 1%/3%/5%，各级之间不累加。购买鱼竿后自动装备最后一根新竿；鱼竿位置不足时拒绝购买，避免购竿后立即溢出出售。钻石与下界合金鱼竿的主动出售需要二次确认，默认 30 秒有效，回收价仍为 0。

## 旧配置升级

2.2 的表格价格直接表示 1 倍下的收购价。默认奖池请恢复默认值；自定义奖池请将旧表格价格减半，再使用 1 倍出售倍率。最低涨跌幅若保存过旧值，手动改为 -50。玩家余额、鱼竿和渔获存档不需重置。
