# 默认经济设定

基础收购价 = 标价 × 1/2；当日市场收购价 = 基础收购价 ×（1 + 涨幅）。最终结果向下取整。标价用于确定渔获价值，铁匠铺出售的两种附魔书也使用这个价格。

默认 50 次每日上限、原抽取权重与市场范围下，无附魔时每日全部渔获的基础收购期望约 **490 绿宝石**。按 365 天不同市场行情测算，全部出售约 **615/日**，仅一键出售普通物品约 **330/日**。这些是扣除维修、购竿和附魔费用前的期望值，实际收益随抽取与行情变化；囤货、双倍产出和自定义奖池会影响结果。
